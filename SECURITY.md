# Security and business data

The application processes files locally. The public repository does not contain operational VSM files, routing extracts, workcentre mappings, material lists or generated business outputs.

Do not attach production workbooks, `.vsdx` files, `.vpa` packages or exported routing data to a public issue. Reproduce a problem with synthetic data and remove names, identifiers and local paths before sharing screenshots.

For a vulnerability that should not be public, use GitHub's private vulnerability reporting for this repository when available.
